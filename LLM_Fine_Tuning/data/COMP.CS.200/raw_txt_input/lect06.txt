Position Position The position of an element can be set with a position attribute static - The element is positioned as in normal flow, default value relative - Element is positioned relative to its "normal" position absolute - Element is positioned relative to the nearest positioned ancestor or if there is no positioned ancestor to the container of the document fixed - Element is positioned relative to the viewport. It has the effect of keeping the element in the same position in the window even when scrolling. sticky - Mixture of relative and fixed positioning. Not yet widely supported. accompanied with top, bottom, left, right to tell the new location. MDN on Position Relative positioning moves an element relative to its normal position set by properties top, bottom, left, right i.e., from top, from bottom, etc. element remains in the document flow the other elements assume it is in its original place elem { position: relative; top: 50px; left: 100px; } Absolute positioning Element is attached to the closest ancestor whose position is other than static taken out from the document flow elem { position: absolute; top: 50px; left: 100px; } Fixed positioning Similar to absolute, but not attached to an ancestor, but to the viewport (the browser window) elem { position: fixed; top: 50px; left: 100px; } Sticky positioning a new, experimental positioning kind-of-a combination of absolute and fixed positioning fixed till a certain threshold, after which absolute elem { position: sticky; top: 50px; left: 100px; } Floats CSS float float sets element's horizontal position: to the left or right edge of its parent aside { float:left; } if scrolled, moves with its parent removal from the document flow following elements occupy the released space the occupation is eliminated with clear A float video A float article CSS float example float: none|left|right Reset of float: clear: right|left|both For example: aside { float:left; } p.cleared { clear: left; } Laboris esse reprehenderit adipisicing consectetur excepteur esse non sit quis exercitation officia amet. This means items can be visually positioned differently than their order in the HTML. order property allows you to further control the order of grid items within a row or column. by default, items have an order of 0. You can set a positive or negative value for each item, similar to the `z-index` property. with a left-to-right main axis, the item with the smallest order value appears on the left, and the largest on the right. grid items can span multiple columns. For example, .item { grid-column: 1 / -1; } makes the item span from the first column (1) to the last line (indicated by `-1`).
