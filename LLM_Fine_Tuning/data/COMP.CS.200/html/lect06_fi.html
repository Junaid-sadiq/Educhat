Sijainti

Sijainti

Elementin sijainti voidaan asettaa position-attribuutilla

  • static - Elementti sijoitetaan normaalin virtauksen mukaisesti, oletusarvo
  • relative - Elementti sijoitetaan suhteessa sen "normaaliin" sijaintiin
  • absolute - Elementti sijoitetaan suhteessa lähimpään asemoituun ylätason elementtiin tai jos sellaista ei ole, dokumentin pääsäiliöön
  • fixed - Elementti sijoitetaan suhteessa näkymäalueeseen. Se pysyy samassa paikassa ikkunassa myös vieritettäessä.
  • sticky - Yhdistelmä suhteellisesta ja kiinteästä asemoinnista. Ei vielä laajasti tuettu.

Yhdistettynä ominaisuuksiin top, bottom, left, right uuden sijainnin määrittämiseksi.

MDN sijainnista

Suhteellinen asemointi

  • siirtää elementtiä suhteessa sen normaaliin sijaintiin
  • määritetään ominaisuuksilla top, bottom, left, right
    • esim. ylhäältä, alhaalta jne.
  • elementti säilyy dokumenttivirrassa
    • muut elementit olettavat sen olevan alkuperäisessä paikassaan
elem {
position: relative;
top: 50px;
left: 100px;
}

Absoluuttinen asemointi

  • elementti otetaan pois dokumenttivirrasta ja
  • se liitetään lähimpään esivanhempaan, jonka asemointi on jotain muuta kuin static
elem {
position: absolute;
top: 50px;
left: 100px;
}

Fixed-asemointi

  • Samanlainen absoluuttiseen asemointiin verrattuna, mutta elementtiä ei liitetä esivanhempaan vaan selainikkunaan (viewport)
elem {
position: fixed;
top: 50px;
left: 100px;
}

Tahmea (sticky) asemointi

  • uusi, kokeellinen asemointitapa
  • ikään kuin yhdistelmä absoluuttisesta ja kiinteästä asemoinnista:
    • pysyy kiinteänä tiettyyn rajaan asti, jonka jälkeen muuttuu absoluuttiseksi
elem {
position: sticky;
top: 50px;
left: 100px;
}

CSS float

  • poistetaan normaalista dokumenttivirrasta
  • seuraavat elementit täyttävät vapautuneen tilan
  • tilan täyttö voidaan estää clear-ominaisuudella
  • Video kelluvista elementeistä Artikkeli kelluvista elementeistä

Lisää termejä

Grid container: grid-template

grid-template: <row-heights>/<column-widths>
.grid {
    display: grid;
    /* 2 x 3 grid */
    grid-template: 50px 50px / 150px auto 150px;
}

auto käyttää jäljelle jääneen tilan

grid-template, joka käyttää fraction(fr)-jakoa

width/3 (= 1 + 1 + 1): samanleveyiset sarakkeet
.container {
grid-template: 50px 50px / 1fr 1fr 1fr;
}
1 + 4 + 5 = 10: sarakkeet 1/10, 4/10 ja 5/10
.container {
grid-template: 50px 50px / 1fr 4fr 5fr;
}

Grid-mallin toistot: repeat

repeat(n, CSS-yksikköarvo)

grid-template: 50px 50px / 1fr 1fr 1fr;

grid-template: repeat(2, 50px) / repeat(3, 1fr);

Grid ja järjestys: normaalin virran häiritseminen

Normaalisti dokumentin sisältö asetellaan esiintymisjärjestyksessä. Grid-layout voi kuitenkin muuttaa tätä:

  • grid antaa mahdollisuuden määrittää layoutin rakenteen ja sijoittaa elementit sen sisälle. Tämä tarkoittaa, että elementit voivat näkyä eri paikoissa kuin niiden järjestys HTML:ssä.
  • order-ominaisuus mahdollistaa grid-elementtien järjestyksen hallinnan rivillä tai sarakkeessa.
    • oletusarvoisesti kaikilla elementeillä on järjestysarvo 0. Voit asettaa positiivisia tai negatiivisia arvoja, samoin kuin `z-index`-ominaisuudessa.
    • vasemmalta oikealle etenevässä pääakselissa pienin order-arvo ilmestyy vasemmalle ja suurin oikealle.
  • grid-elementit voivat ulottua useiden sarakkeiden yli. Esimerkiksi, .item { grid-column: 1 / -1; } venyttää elementin ensimmäisestä sarakkeesta (1) viimeiseen linjaan (merkitty `-1`:llä).

Yhteenveto grid-asettelun vaihtoehdoista

Grid-kontaineri
grid-template-rows rivien korkeudet
grid-template-columns sarakkeiden leveydet, esim. 1em 1em auto 1em
grid-template rivit/sarakkeet
grid-template-areas "ASCII-taide"
row-gap, column-gap, gap "marginaalit"
Grid-elementit
grid-row rivi-alku/-loppu
grid-column sarakkeen alku/loppu
grid-area rivi/sarake (oletusarvo 1) tai rivi-alku/sarake-alku/rivi-loppu/sarake-loppu
subgrid sisäkkäinen grid, joka kohdistaa rivit ja sarakkeet pääkontainerin kanssa

Mukautetut ominaisuudet

Mukautetut ominaisuudet

  • tunnetaan myös CSS-muuttujina
  • määritettyjä arvoja, joita voidaan käyttää uudelleen koko dokumentissa
  • syntaksi:
    1. kaksoisviiva: 
      :root { --primary-color: #3498db; }
      määrittää ominaisuuden koko dokumentille (:root-pseudoluokka)
    2. @property; ei vielä laajasti tuettu 
      @property --item-size {
    syntax: "<percentage>"; /* Sallii vain prosenttiarvot */
    initial-value: 40%; /* Asettaa oletusarvon */
}

Käyttö var()-funktion kanssa

  • var() on CSS-funktio, jota käytetään mukautetun ominaisuuden (muuttujan) arvon lisäämiseen
  • Sintaksi: 
    var(--variable-name, 
            oletusarvo)
  • Jos muuttujaa ei ole määritetty, se palautuu oletusarvoon.
.button {
    background-color: 
        var(--primary-color, blue);
    color: white;
}    
.container {
    width: var(--item-size); 
    height: var(--item-size); 
}
