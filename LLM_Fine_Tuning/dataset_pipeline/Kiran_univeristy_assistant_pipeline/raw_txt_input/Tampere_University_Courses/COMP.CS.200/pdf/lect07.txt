Either or both of these parameters can be made more flexible. 6 multiplier 2. minmax(min, max) Width can be defined as minmax() range that attempts to guarantee a decent space for the content with min. Here, as a mix of absolute and fraction values: minmax(100px, 1fr) grid-template-columns: repeat(3, minmax(100px, 1fr)) 250px; ●if 1fr > 100px, the width is 1fr ●if 1fr < 100px, the width is min-width: 100px; // the rest is taken from 250px a. The last column, 250px is used as a “buffer" taking what is left from 3 * minmax(). Based on the chosen strategy, elements may overflow or wrap, and if space is very limited, also the min width may be compromised. 7 3. auto-fill vs. auto-fit In bad design, elements start to overflow. In the worst case, they are not visible anymore. To make a grid container responsive, the first repeat() parameter, the multiplier N, must also be "gridified" in addition to minmax() of length For the purpose, there is the last step: auto-fill vs auto-fit. grid-template-columns: repeat(auto-fill, minmax(100px, 1fr)) 250px; grid-template-columns: repeat(auto-fit, minmax(100px, 1fr)) 250px; 8 auto-fill vs. -fit differ if there is space to grow If minmax(100px, 1fr): auto-fill: min of 100px is used, auto-fit: max of 1fr is used instead. 9 Responsive grid: mnemonic 10 Fig. A pizza fraction triggers Niilo to a responsive repeat(auto-fill, minmax(empty, full)) - Niilo cannot live off his nerdy grid! @media (media-type) { css-rule } Media queries o Adapting to different devices with CSS3 media queries 11 @media (media-feature) { css-rule } @media (media-type and media-feature) { css-rule } true / false rule applies, if the corresponding media-feature is true index Media query: media-features o Media-features: width | min-width | max-width | height | min-height | max-height| aspect-ratio | color | resolution | orientation | scan … 12 @media (min-width: 768px) { css-rule } @media (min-width: 768px) and (max-width: 991px) { css-rule } index Media query: media-type o Media-types: all | aural | braille | handheld | print | projection | screen | tty | tv | embossed | speech .. 13 @media (min-width: 700px), handheld and (orientation: landscape) { css-rule } @media (print) { css-rule } index Typical media-query o Basic style rules and special style rules for certain screen widths • first we define the rules that apply regardless of the window width • with media queries we change the basic style rules, or add new rules for certain situations 14 p { color: blue; } @media (min-width: 1200px) { rules for wide screens only } @media (min-width: 992px) and (max-width: 1199px) { rules for laptop sized screens } … Non-overlapping widths index Bootstrap http://getbootstrap.com/ 15 o Most popular?
