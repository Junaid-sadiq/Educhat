Insertion sort 1. Introduction 2. Algorithm presentation 3. Operation counts: best, worst, average 1. Introduction Insertion sort is a sorting algorithm. Sorting: placing elements in order (smallest to largest or largest to smallest) Assumption: for two elements x, y, only three possible cases: (i) x < y, (ii) x = y or (iii) x > y Insertion-sort: • can be used to sort items/elements in an array or list • an example of decrease and conquer • easy to understand/code • one of many diﬀerent sorting algorithms 2.
