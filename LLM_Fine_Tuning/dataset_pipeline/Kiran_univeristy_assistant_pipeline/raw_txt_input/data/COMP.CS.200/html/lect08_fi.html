Muuttujan nimi (tunniste)

  • JavaScript on kirjainkoolle herkkä (case-sensitive).
  • Muuttujan nimi voi sisältää:
    • kirjaimia, numeroita, alaviivoja (esim. varName, this_one_too)
    • ei voi alkaa numerolla (esim. 99_notAllowed, isAllowed_99)
    • funktioiden nimeämisessä suositaan camelCase-tyyliä (esim. getValue)
  • Varattuja sanoja ei voi käyttää muuttujien niminä, esim. https://www.w3schools.com/js/js_reserved.asp.

Paikallisten muuttujien alue

  • function scope
    • var
    • Sisältää funktiolohkon
    • var:n nostaminen (hoisting)
      • muuttujan määrittely "nostetaan" funktion alkuun
      • käytä mieluummin let tai const kuin var
  • block scope
    • let, const
    • Sisältää lausekelohkon - {}
function getValue(condition){
    // color hoisted here as undefined
    if(condition){
        var color = "blue";
        return color;
    }
    else{
    // color exists here as undefined
    }
}
function getValue(condition){
    // color does not exist here
    if(condition){
        let color = "blue";
        return color;
    }
    else{
        // color does not exist here
    }
    // color does not exist here
}

Muuttujat: const

  • Parantaa muuttumattomuutta (hyödyllinen estämään tahattomia muutoksia)
    • ✅ Estää tahattomat tyypin muutokset
    • ✅ Varmistaa ennustettavat arvot
  • Nimeämiskäytäntö: Vakiot kirjoitetaan yleensä isoilla kirjaimilla
    • Esimerkki: const MAX_USERS = 100;
  • Julistetaan kerran - uudelleenmäärittely ei ole sallittua!
    •                 
                const PI = 3.141592653589793;
                PI = 3.14;      // ❌ Virhe: Vakion arvon muuttaminen
                PI = PI + 10;   // ❌ Virhe: Vakion arvon muuttaminen
  • ⚠️ Huomautus: const estää objektin uudelleenmäärittelyn, mutta ei tee objektista itsestään muuttumatonta. 
    •                 const user = { name: "Alice", age: 25 };
                
// ✅ Sallittua: Objektin ominaisuuksien muuttaminen
user.age = 30;
console.log(user.age); // 30

// ❌ Virhe: Objektin uudelleenmäärittely
user = { name: "Bob", age: 40 }; 
// TypeError: Vakion arvon muuttaminen

Laiska ja dynaaminen tyypitys

  • Määrittely ja alustus voidaan tehdä erikseen, eli löyhästi, tai ne voidaan yhdistää
    • let count, name;            // muuttujalla ei ole vielä tietotyyppiä
count = 0;                  // numero-muuttuja
name = "Charles Dickens";   // merkkijono-muuttuja
let number2 = 12;           // uusi numero-muuttuja
name = 123;                 // muuttuu kokonaisluvuksi (!)
name = "Uusi nimi";        // muuttuu takaisin merkkijonoksi, ei sallittu const:lla
  • Muuttujan tietotyyppi määritetään dynaamisesti annettavan arvon perusteella
  • Voiko muuttujaa käyttää ilman, että se on ensin määritelty?
    • Kyllä, mutta JavaScript määrittää sen automaattisesti globaaliksi muuttujaksi.
    • Tämä tapahtuu vain ei-tiukassa tilassa.
    • Tiukassa tilassa ("use strict";) määrittelemättömän muuttujan käyttö aiheuttaa virheen. Tiukka tila on suositeltava.

Paikallinen ja globaali laajuus

  • Paikalliset muuttujat
    • Saatavilla vain funktion sisällä
  • Globaalit muuttujat
    • Määritelty funktion ulkopuolella
    • Muuttujat, joita käytetään ilman määrittelyä
    • Näkyvät kaikkialla
    • Globaali laajuus voi olla haitallinen, koska:
      • Sivuvaikutukset ja ei-toivotut taustamuutokset
      • Varjostaa muita globaaleja muuttujia
      • Kirjastot vaikeuttavat globaalien muuttujien hallintaa
    let a = 5;      // globaali muuttuja
let sum = 0;    // globaali muuttuja

function teeJotain() {
    let b = 12; // paikallinen muuttuja
    c = 10;     // globaali (!)
}
/* tässä b ei ole olemassa, mutta c on */

window-objekti globaalina laajuutena

  • Mikä on window-objekti?
    • Selaimen globaali objekti, joka edustaa selainikkunaa
    • Tarjoaa pääsyn selaimen ominaisuuksiin ja API:hin
    • Jokainen globaali muuttuja ja funktio on window-objektin ominaisuus
  • window välittäjänä
    • Toimii käyttöliittymänä JavaScriptin ja selaimen välillä
    • Yhdistää JavaScriptin selainkohtaisiin toiminnallisuuksiin:
      • DOM → verkkosivun sisällön muokkaus
      • BOM → historia, sijainti, navigointi jne.
      • Tapahtumankäsittely → Ajastimet, hiiri/näppäimistötapahtumat

Taulukot

Taulukko

  • Taulukko esitetään Array-objektina. Luodaksesi taulukon, jossa on N elementtiä, voit kirjoittaa
    • let myArray = new Array(N);
  • Taulukon indeksit kulkevat välillä 0 - N-1.
  • JavaScript sallii erilaisten arvojen tallentamisen taulukkoon
  • Ominaisuus length kertoo taulukon alkioiden määrän.
  • Sisältää useita metodeja elementtien käsittelyyn, esim.
    • reverse(), push(), concat(), flat() jne.

Taulukon Määrittelyesimerkkejä

// Taulukko, jossa on 3 alkiota, jokainen undefined
                let Car = new Array(3);
                
                // Aseta arvoja alkioille
                Car[0] = "Ford";
                Car[1] = "Toyota";
                Car[2] = "Honda";
                
                // Luo taulukko kolmella alustetulla alkiolla
                let Car2 = new Array("Ford", "Toyota", "Honda");
                
                // Sama taulukko eri syntaksilla
                let Car3 = ["Ford", "Toyota", "Honda"];

Arvojen määrittäminen taulukkoon

// Taulukko, jossa on 3 alkiota ja eri tietotyyppejä
                let tmp3 = new Array(1, "a", true);
                
                // Muuttaa tmp3-taulukon 10 alkiota pitkäksi
                // alkioista tmp3[3] - tmp3[9] tulee undefined
                
                tmp3.length = 10; 
                
                // Muuttaa tmp3-taulukon 100 alkiota pitkäksi
                tmp3[99] = "Jotain";
                // alkioista tmp3[3] - tmp3[98] tulee undefined. Taulukko on harva.

Alkioiden lisääminen ja poistaminen

  • arr.push(…items) - lisää alkioita loppuun,
  • arr.pop() - poistaa alkion lopusta,
  • arr.shift() - poistaa alkion alusta,
  • arr.unshift(…items) - lisää alkioita alkuun.
  • HUOM: Kaikki nämä funktiot muuttavat alkuperäistä taulukkoa
    • taulukon alkioiden määrä muuttuu
    • arr.shift() ja arr.unshift() muuttavat myös alkioiden indeksejä

... Spread-syntaksi

  • Spread (...) -syntaksi:
    • laajentaa iteroitavan, kuten taulukon tai merkkijonon, yksittäisiksi alkioiksi (tai merkkijonoissa merkeiksi).
      • sisäänrakennettuja iteroitavia ovat esimerkiksi String, Array, TypedArray, Map, Set
    • luettelee objektin ominaisuudet ja lisää ne avain-arvopareina uuteen luotavaan objektiin.
  • Spread-syntaksia voi käyttää, kun kaikki objektin tai iteroitavan alkioita tarvitaan uudessa taulukossa tai objektissa.

... Spread taulukoissa

// Taulukon kopiointi
const arr = [1, 2, 3];
const arr2 = [...arr]; // arr.slice()

arr2.push(4);
//  arr2 muuttuu: [1, 2, 3, 4]
//  arr pysyy muuttumattomana

// Vaihtoehto taulukoiden yhdistämiseen
const evens = [2, 4, 6, 8, 10];
const odds = [1, 3, 5, 7, 9];
const all = [...evens, ...odds]; // evens.concat(odds)

arr.concat(arg1, arg2…)

  • Metodi arr.concat() luo uuden taulukon, joka sisältää arvoja muista taulukoista.

  • arr.concat() ei muuta mitään annetuista taulukoista, vaan palauttaa uuden matalan kopion, joka sisältää alkuperäisten taulukoiden alkioita.

Taulukoiden yhdistäminen

const letters = ['a', 'b', 'c'];
const numbers = [1, 2, 3];
const alphaNumeric = letters.concat(numbers);
// alphaNumeric: ["a", "b", "c", 1, 2, 3]
// "letters" ja "numbers" pysyvät muuttumattomina

for..of Toistorakenne taulukoille ja muille iteroitaville

  • for...of-lause suorittaa toistorakenteen, joka käy läpi iteroitavan objektin arvot.
  • for..of ei anna pääsyä alkion indeksiin, vain sen arvoon.
  • Sisäänrakennettuja iteroitavia ovat Array, String, Map, Set, NodeList (ja muut DOM-kokoelmat).
  • break ja continue toimivat kuten muissakin toistorakenteissa.

Määrittelyt vs. lausekkeet

  • Funktion määrittely
                            function square(value) {return value * value;}
  • Funktio lausekkeena
                            let square = function(value) {
                        return value * value;
                    }; // Huomaa puolipiste!
  • Funktiolauseke on anonyymi, koska sillä ei ole nimeä.
  • Funktion voi kirjoittaa myös nuolifunktiosyntaksilla:
                            const square = (value) => value * value;

Takaisinkutsufunktiot (callback functions)

  • Kun funktio A annetaan parametrina funktiolle B, ja B suorittaa A:n, A on 'takaisinkutsufunktio'.
  • Mahdollistaa muiden kirjoittamien funktioiden käyttämisen ja oman toiminnan määrittelyn.
  • Esimerkiksi tapahtumankäsittelyssä.

Kommentit JavaScriptissä

// tämä on kommentti
                    
                    /* tämä on
                    monirivinen kommentti */
