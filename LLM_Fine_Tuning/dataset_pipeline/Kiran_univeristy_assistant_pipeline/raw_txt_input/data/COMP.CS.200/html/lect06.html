Position

Position

The position of an element can be set with a position attribute

  • static - The element is positioned as in normal flow, default value
  • relative - Element is positioned relative to its "normal" position
  • absolute - Element is positioned relative to the nearest positioned ancestor or if there is no positioned ancestor to the container of the document
  • fixed - Element is positioned relative to the viewport. It has the effect of keeping the element in the same position in the window even when scrolling.
  • sticky - Mixture of relative and fixed positioning. Not yet widely supported.

accompanied with
top, bottom, left, right to tell the new location.

MDN on Position

Relative positioning

  • moves an element relative to its normal position
  • set by properties top, bottom, left, right
    • i.e., from top, from bottom, etc.
  • element remains in the document flow
    • the other elements assume it is in its original place
elem {
position: relative;
top: 50px;
left: 100px;
}

Absolute positioning

  • Element is attached to the closest ancestor whose position is other than static
  • taken out from the document flow
elem {
position: absolute;
top: 50px;
left: 100px;
}

Fixed positioning

  • Similar to absolute, but not attached to an ancestor, but to the viewport (the browser window)
elem {
position: fixed;
top: 50px;
left: 100px;
}

Sticky positioning

  • a new, experimental positioning
  • kind-of-a combination of absolute and fixed positioning
  • fixed till a certain threshold, after which absolute
elem {
position: sticky;
top: 50px;
left: 100px;
}

Grid container contains grid items

More terminology

line
row line or column line
track
between adjacent lines (hover rows)
cell
surrounded by adjacent rows and columns (hover to see row tracks)
area
rectangle of one/multiple cells

Grid container: grid-template

grid-template: [CSS unit]*/[CSS unit]*
.grid {
    display: grid;
    /* 2 x 3 grid */
    grid-template: 50px 50px / 150px auto 150px;
    }

auto occupies remaining space

grid-template with fraction(fr)

width/3 (= 1 + 1 + 1): equal-width columns
.container {
grid-template: 50px 50px / 1fr 1fr 1fr;
}
width/10 (= 1 + 4 + 5): columns 1/10, 4/10 and 5/10
.container {
grid-template: 50px 50px / 1fr 4fr 5fr;
}

Grid template shorthand: repeat

repeat(n, CSS unit value)

equals n times repeated CSS unit value, e.g.

grid-template: 50px 50px / 1fr 1fr 1fr;
== 
grid-template: repeat(2, 50px)/ repeat (3, 1fr);

Grid areas: multiple grid cells

grid-column: start-value/end-value | start-value/span value
grid-row: start-value/end-value | start-value/span value

  • grid-column and grid-row define multiple cells between specified grid lines; Example in CSS tricks

Grid and order: disrupting the normal flow

The normal document flow lays elements out in the order of appearance.Grid layout, however, can disrupt this:

  • grid allows you to define a layout structure and then place items within that structure. This means items can be visually positioned differently than their order in the HTML.
  • order property allows you to further control the order of grid items within a row or column.
    • by default, items have an order of 0. You can set a positive or negative value for each item, similar to the `z-index` property.
    • with a left-to-right main axis, the item with the smallest order value appears on the left, and the largest on the right.
  • grid items can span multiple columns. For example, .item { grid-column: 1 / -1; } makes the item span from the first column (1) to the last line (indicated by `-1`).

Summary of grid layout options

Grid container
grid-template-rows row heights
grid-template-columns column widths, e.g., 1em 1em auto 1em
grid-template rows/columns
grid-template-areas "ascii-art"
row-gap, column-gap, gap "margins"
Grid items
grid-row row-start/-end
grid-column col-start/-end
grid-area row/column (defaults to 1) or row-start/col-start/row-end/col-end
subgrid nested grid as subitem to align tracks with parent

Custom properties

Custom properties

  • also referred to as CSS variables
  • specific values that can be reused throughout a document
  • syntax:
    1. double-hyphen: 
      :root { --primary-color: #3498db;}
      the property actionable throughtout the document (:root pseudo-class)
    2. @property; not yet widely supported 
      @property --item-size {
    syntax: "<percentage>"; /* Allow only percentage values */
    initial-value: 40%; /* Set an initial value */
}

Usage with var() function

  • var() is a CSS function used to insert the value of a custom property (variable)
  • Syntax: 
    var(--variable-name, 
default-value)
  • If the variable is not defined, it falls back to the default value.
.button {
    background-color: 
        var(--primary-color, blue);
    color: white;
}    
.container {
    width: var(--item-size); 
    height: var(--item-size); 
}
