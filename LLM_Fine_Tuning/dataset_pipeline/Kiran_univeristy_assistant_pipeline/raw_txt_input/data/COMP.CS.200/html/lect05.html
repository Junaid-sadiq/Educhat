CSS basics

CSS: Cascading Style Sheets

CSS (Cascading Style Sheets) is a language that styles the presentation of HTML content on web pages. It offers a two-part system for applying styles:

  • Cascading: styles are applied from different sources with a specific order:
    • User Agent: default styles defined by the web browser.
    • Author: Styles you define in your CSS files.
    • User: Styles a user can set in their browser preferences.
  • Styles defined for parent elements in the HTML structure can be inherited by their child elements, unless overridden by more specific styles.

Selector e.g. element type, class or id

The same rule targeted at several elements

h1, h2 { /* headers blue */

Several rules targeted at the same element

Attaching styles

Method 1: External Stylesheet (Linking a CSS File)

Uses a separate .css file (or multiple files) attached via the <link> element in the <head> section.

This method allows styles to be reused across multiple pages, improving maintainability.

<head>
                    <meta charset="UTF-8" />
                    <title>Page Title</title>
                    <link rel="stylesheet" type="text/css" href="path/basic.css" />
                    <link rel="stylesheet" type="text/css" href="path/navigation.css" />
                    <link rel="stylesheet" type="text/css" href="path/special.css" />
                </head>

Method 2: Internal Stylesheet (Using a <style> Block)

Defines CSS rules inside a <style> element within the <head> of the document.

Styles apply only to this page and are not shared with other documents.

Useful for quick modifications or single-page styling but harder to maintain for larger sites.

<html lang="fi">
                <head>
                    <meta charset="UTF-8" />
                    <title>Page Title</title>
                    <style>
                    body {
                        background-color: maroon;
                        margin-left: 20px;
                    }
                
                    p {
                        color: white;
                    }
                    </style>
                </head>

Attaching styles: method 3

Straight in to an element on a page using the style-attribute, so called inline style

Rule priorities

Several rules for the same element

How to decide the layout of an element? The following three concepts should be understood.

Specificity

  • selectors have a certain specificity value
  • the rule with the most specific selector "wins"

Cascading

  • when several rules have same specificity value, the "last" rule wins

Inheritance

  • some properties are inherited from their parent (not all)

Specificity

Each selector has a specificity value as follows

Selector Specificity
element, pseudo-element 1
class, pseudo-class, attribute 10
id 100
inline 1000

The specificity of a combined selectors are computed as a sum of the specificity values involved, e.g.

p::after type and a pseudo-element selectors 1+1 = 2
[type=email] attribute selector 10
p.important type and class 1+10=11
aside.chart:first-child type, class, pseudo-class 1+10+10=21

Try the css-specificity-calculatory by Polypane

Cascading

  1. user-agent stylesheet, i.e., default browser styles
  2. user stylesheet, user defined styles, e.g., vision impaired users (e.g. for Firefox via userContent.css -file)
  3. author stylesheet, i.e., styles set by web developers in the web page itself, where styles are..
    • linked as a separate CSS file
    • in <head> as a style element
    • in an element defined with a style attribute
    • cascade layers 💥new!

Even more nuanced (e.g., transitions), check MDN

Cascade layers (emerging)

  • More modular CSS 
    @layer layer-name {rules}
@layer layer-name;
@layer layer-name, layer-name, layer-name;
@layer {rules}
  • better separation of concerns which improves code maintainability
  • consistent use of CSS layers helps address the issue of conflicting styles
  • placing related rules in the same layer, solves the interference problem
  • combinations of multiple layers is possible

Inheritance

For example, color is inherited, but border is not, e.g., blue text color defined for whole page at once, not for each child separately:
body { color: aquamarine; }

  • However if you define a list element with borders (e.g., <ul>), its children (i.e., <li> elements) are displayed without borders, unless you define:
    li { border: inherit; }
    the property is set to be inherited
  • Also, some properties have initial values, for example, background-color is transparent by default

!important

  • overrides all rules previously assigned to an element
  • used in special situations only, for example
    • visually impaired users may write a rule in the user style sheet (browser file userContent.css) 
      body { font-size: large; !important}
    • should not be used in normal stylesheets, even if it sometimes feels tempting

A general guideline when writing CSS

  • aim to keep the selectors general and simple
  • you can use specific selectors, but only when really in need
  • CSS gets easily scattered
    • the more high-specificity selectors you use, the more difficult is the maintance of the stylesheets

CSS units (of length measure)

                    
    
                        
  • Used to define lengths and sizes in CSS rules.
                            The absolute units: in, cm, mm, pt, pc
                            
      
                                
    • not useful on screen, might get used on some other medium
                                
      • 
                            
    
                        
  •  Pixel (px) is a very commonly used one, e.g,
                            
      
                                
    • min-width: 200px; font-size: 16px;
                                
      • 
                            
    
                        
  •  In addition to absolute, many units are relative
                            
      
                                
    • relative with respect to parent element or to the viewport (= visible part of
                                    the page)


                                
      • 
                            
    
                        
  •  Relative units include: %, em, rem, ex, ch, vh, vw
                            
      
                                
    • note: no space between the number and the unit, e.g.

                                    16px, 0.75em, 1.25rem, 80%, 90vh, 85vw
                                
      • 
                            
    

                

                

                    
Relative units

                    

                        %
                        relative to parent dimensions, handy when the parent's dimensions are set
                        however often tricky in the vertical dimension
                        if parent element doesn't have an explicit height set, the child percentage is always 0
                    

                    

                        em
                        relative to its parent's font-size (height of the font)
                        usually the default font-size (for the body element) in browsers is 16px
                    

                    

                        rem
                        relative to the font size of the root element
                    

                    

                        ex
                        height of the letter "x" (small x) in the used font
                    

                    

                        ch
                        the width of the number "0" in the used font
