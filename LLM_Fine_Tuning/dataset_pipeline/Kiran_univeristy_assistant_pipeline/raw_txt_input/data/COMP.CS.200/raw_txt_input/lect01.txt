URL is a human-readable name, not a numeric IP address. The Domain Name System (DNS) solves the domain name (e.g. m.yle.fi) to a correct IP address. The IP address is used in routing (network layer) In the IPv4, addresses range from 0.0.0.0 to 255.255.255.255 On top of IP layer, TCP/UDP is used as a transport layer, more info OSI vs TCP/IP model OSI Layer TCP/IP layer Description Examples Application Application enables apps communicate with each other, e.g., over HTTP HTTP, FTP, SMTP, DNS Presentation en/de/crypts the content, compresses and formats data (e.g. char sets) - Session establishes connections, manages sessions between applications RPC, SSH Transport Transport controls network traffic, segments data, adds source and destination ports TCP/UDP Network Network routes packets via best path between networks IP, ICMP (ping), routers Data Link Data Link transfers data frames within a network MAC addresses, Ethernet, switches Physical Physical transmits raw bit stream cables, hubs Mnemonic: All People Seem To Need Data Protocols Web standards Standards: history in short W3C standardizes WHATWG develops/innovates Evolution of HTML Standards Year Organization Standard 1989 no formal standards HTML 1.0-2.0 1995 W3C HTML3 3.0-4.1 2000 W3C XHTML 1.0 2003 WHATWG (Mozilla, Opera, Apple) Cont. of HTML, DOM, fetch 2006-2007 W3C + WHATWG collaboration on HTML standards=>living standards 2014 -"- HTML5 2016 -"- HTML5.1 W3 Consortium A community for free and open Web standards Member-driven organization, non-profit organization W3C's vision for "One Web" brings together thousands of dedicated technologists representing more than 400 member organizations and dozens of industry sectors. W3C standards define an Open Web Platform for application development, such as HTML CSS Scalable vector graphics (SVG) Web open font format (WOFF) the Semantic Web stack XML and a variety of other APIs developers, designers, and anyone passionate about the Web have a place to hold discussions and publish ideas For more information see https://www.w3.org/. WHATWG: Driving Web Standards Evolution WHATWG, a collaborative initiative, drives the evolution of web standards. Founded in response to disagreements over the direction of web standards by industry leaders. WHATWG champions innovation and progress in web technologies, including: HTML, CSS, JavaScript APIs Web APIs for multimedia, storage, and communication Web Interface Definition Language (WebIDL) and other emerging web technologies Active participation from developers, designers, and enthusiasts fuels the continuous evolution of web standards within WHATWG's collaborative framework.
