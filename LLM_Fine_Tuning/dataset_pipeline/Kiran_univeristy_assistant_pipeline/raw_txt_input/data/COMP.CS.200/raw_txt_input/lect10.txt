Setting this explicitly Methods (functions as object's properties) this func.call(), func.apply(), func.bind() Creating multiple similar objects new operator and constructor functions Binding this yourself func.call() and func.apply() - invoke function with a different this func.bind() - create a new function with a different this func.call() and func.apply() Binding this to a different object at function call-time func.call() - arguments provided individually func.apply() - arguments provided as an array Both invoke the function immediately, and modify the context. The only difference is how you pass your own arguments. // Syntax func.call(obj); func.call(obj, param1, ..., paramN); func.apply(obj); func.apply(obj, [param1, ..., paramN]); // array to pass the args func.call() and func.apply() example let user = { name: 'John' }; let user2 = { name: 'Jane' }; function greet(city, state) { console.log(this.name + 'from' + city + ', ' + state); } greet.call(user, 'Dallas', 'Texas'); // "John from Dallas, Texas" greet.call(user2, 'Miami', 'Florida'); // "Jane from Miami, Florida" const args = ['Dallas', 'Texas']; greet.apply(user, args); // "John from Dallas, Texas" greet.apply(user2, ['Miami', 'Florida']); // "Jane from Miami, Florida" func.bind() The func.bind() method creates a new function that, when called, has its this keyword set to the provided value, with a given sequence of arguments preceding any provided when the new function is called. Does not invoke the function, it just allows you to bind whatever object you want, you have to call the function yourself. // Syntax func.bind(obj); func.bind(obj, param1, ..., paramN); func.bind() example let user = { name: 'John' }; let user2 = { name: 'Jane' }; function greet(city, state) { console.log(this.name + 'from' + city + ', ' + state); } const introduce = greet.bind(user2, 'Miami', 'Florida'); introduce(); // Prints: "Jane from Miami, Florida" this and method chaining as design pattern Important to recognize what is happening only one statement chaining all the methods let student1 = new Student() .setFirstName('Ahto') .setLastName('Simakuutio') .setCourseName('Web Site Development') .setEntryYear(2025) No-chain vs. method chain class Student1 { constructor() { this.firstName = ''; this.lastName = ''; } setFirstName(value) { this.firstName = value; } setLastName(value) { this.lastName = value; } } methods don't return anything methods must be called separately class Student2 { constructor() { this.firstName = ''; this.lastName = ''; } setFirstName(value) { this.firstName = value; return this; } setLastName(value) { this.lastName = value; return this; } } methods return this method calls can be chained No-chain vs. method chain (continued) No-chain // call each method separately let s1 = new Student1(); s1.setFirstName('Ahto'); s1.setLastName('Simakuutio'); Method chain // chain methods let s2 = new Student2() .setFirstName('Ahto') .setLastName('Simakuutio'); Method chaining Method returns this the object itself is returned from the method calling another method on the same object can be chained Getters and other methods which return other data cannot be chained this summary In a method, this refers to the owner object. In a function, to the global object, however, in strict mode, this is undefined Alone, this refers to the global object (window in a browser) func.call(), func.apply(), and func.bind() can bind this to any object.
