It offers a two-part system for applying styles: Cascading: styles are applied from different sources with a specific order: User Agent: default styles defined by the web browser. Author: Styles you define in your CSS files. User: Styles a user can set in their browser preferences. Styles defined for parent elements in the HTML structure can be inherited by their child elements, unless overridden by more specific styles. Click the green nodes in the tree Attaching styles Method 1: External Stylesheet (Linking a CSS File) Uses a separate .css file (or multiple files) attached via the <link> element in the <head> section. This method allows styles to be reused across multiple pages, improving maintainability. <head> <meta charset="UTF-8" /> <title>Page Title</title> <link rel="stylesheet" type="text/css" href="path/basic.css" /> <link rel="stylesheet" type="text/css" href="path/navigation.css" /> <link rel="stylesheet" type="text/css" href="path/special.css" /> </head> Method 2: Internal Stylesheet (Using a <style> Block) Defines CSS rules inside a <style> element within the <head> of the document. Styles apply only to this page and are not shared with other documents. Useful for quick modifications or single-page styling but harder to maintain for larger sites. <html lang="fi"> <head> <meta charset="UTF-8" /> <title>Page Title</title> <style> body { background-color: maroon; margin-left: 20px; } p { color: white; } </style> </head> Attaching styles: method 3 Straight in to an element on a page using the style-attribute, so called inline style This is a paragraph. The absolute units: in, cm, mm, pt, pc not useful on screen, might get used on some other medium Pixel (px) is a very commonly used one, e.g, min-width: 200px; font-size: 16px; In addition to absolute, many units are relative relative with respect to parent element or to the viewport (= visible part of the page) Relative units include: %, em, rem, ex, ch, vh, vw note: no space between the number and the unit, e.g. 16px, 0.75em, 1.25rem, 80%, 90vh, 85vw Relative units % relative to parent dimensions, handy when the parent's dimensions are set however often tricky in the vertical dimension if parent element doesn't have an explicit height set, the child percentage is always 0 em relative to its parent's font-size (height of the font) usually the default font-size (for the body element) in browsers is 16px rem relative to the font size of the root element ex height of the letter "x" (small x) in the used font ch the width of the number "0" in the used font Viewport units (vw/vh) vs pixels 100 vw = 100% of viewport width viewport px relative, like %-unit for both horizontal and vertical dimensions instead of percentage of the parent, it is percentage of the screen (aka viewport). vh refers to one percent of viewport height, and vw to one percent of viewport width 100 vh = 100% of viewport height 1px = 1/96 of 1 inch, not relative corresponds to one device pixel high resolution (retina) displays 1px may be several device pixels vh and vw do not suffer from the parent limitation that the % unit does a pixel wide line is always sharp Examples In most browsers, the default font-size (for the body element) is 16px Font size is one of the inherited properties children inherit the text size of their parent no need to repeat, unless text size is changed Which units to use?
