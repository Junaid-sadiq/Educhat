Written A -> B In our example: (name) is a key. Everything is FD on this key Plus cid -> size Problems: 1) redundancy: cage_size repeated for each animal in the case 2) cannot have an empty cage Issue: Cage_size is functionally dependent on cid which in turn is functionally dependent on name. So called transitive dependency. Solution normaliziation; Cage (id, cage_size) Animals (name, species, age, c_id) 1NF (Codd) -- all tables “flat” 2NF (Codd) -- no transitive dependencies 3NF (Codd) -- fully functional on key BCNF 4NF 5NF P-J NF ….
