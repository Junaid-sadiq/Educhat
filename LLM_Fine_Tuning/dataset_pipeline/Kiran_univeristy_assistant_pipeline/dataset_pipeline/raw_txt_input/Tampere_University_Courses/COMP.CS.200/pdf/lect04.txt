combinations in text strings 16 index © Web-CAIS Pia Niemelä, based on Aulikki Hyrskykari’s original slides a — matches one character that is a (not b, not aa, etc.) abc — matches a, followed by b, followed by c a* — matches the character a, zero or more times (+ matches a character one or more times) ^a — matches a string which starts with a a|b — matches one character that is a or b [abc] — matches one character that is a, b, or c ^[abc] — matches a string starting with a, b, or c (note the difference with [^abc]) [a-z] — matches any character in the range a–z, lower case only ( [A-Za-z] for lower and upper case, and [A-Z] for upper case only) a.c — matches a, followed by any character, followed by c a{5} — matches a, 5 times a{5,7} — matches a, 5 to 7 times, but no less or more Numbers and other characters in these expressions too, such as: [-] — matches a space or a dash [0-9] — matches any number in the range 0 to 9 Regular expressions 17 index © Web-CAIS Pia Niemelä, based on Aulikki Hyrskykari’s original slides Examples of regular expressions 18 [Mm].*k — A single character that is an upper or lowercase m, followed by zero or more characters of any type, followed by a single lowercase k. [A-Z][a-z]+ — A single upper case character followed by one or more lower case letters. [0-9]{3}[ -][0-9]{7} — A simple match for a Finnish domestic phone number — three numbers, followed by a space or a dash, followed by seven numbers index <input type="text" id="town" pattern="[A-Z][A-Za-z' -]+" minlength="2"> Accepts Manchester, Ashton-under-lyne, and Bishop's Stortford. © Web-CAIS Pia Niemelä, based on Aulikki Hyrskykari’s original slides
