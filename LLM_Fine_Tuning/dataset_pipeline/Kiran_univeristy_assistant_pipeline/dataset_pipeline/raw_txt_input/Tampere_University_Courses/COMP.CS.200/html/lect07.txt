Media queries Media queries enable responsive design, and more.. support, e.g., pointer types, resolutions, aspect-ratios adaptation to display capabilities/user-preferences can be done in a fine-grained manner during this course, flex/grid are the primary means of implementing responsive designs and media queries only a complementing technique @media in CSS @media belongs to so-called at-rules (other rules are e.g. @import, @property, @supports, ...) inside the @media rule, you define a media query that specifies when the following styles should be applied. media queries are written within parentheses () Media query options media features are conditions that check device capabilities, such as screen size (min-width: 900px), resolution (resolution: 720dpi), or orientation (orientation: landscape) media types define the target device or environment, like screen (for desktops and laptops), print (for printing), speech (for screen readers), or even a generic all. combinations of these using logical operators like and, or (comma), not, or only to create more complex conditions Media query: media-features width | min-width | max-width | height | min-height | max-height| aspect-ratio | color | resolution | orientation | scan ... @media (min-width: 768px) { css-rule } @media (min-width: 768px) and (max-width: 991px) { css-rule } Media query: media-type all | aural | braille | handheld | print | projection | screen | tty | tv | embossed | speech ... @media (print) { css-rule } @media (min-width: 700px), handheld and (orientation: landscape){ css-rule } For more, check this site W3Schools material Typical media query Basic style rules and special style rules for certain screen widths. First we define the rules that apply regardless of the window width. With media queries we change the basic style rules, or add new rules for certain situations. p { color: blue; } /* Remember, non-overlapping widths!*/ @media (min-width: 1200px) { rules for wide screens only } @media (min-width: 992px) and (max-width: 1199px) { rules for laptop sized screens } Typical viewport widths Small phone < 600px Phone 600px - 767px Tablet 768px - 991px Desktop 992px - 1199px Wide desktop >= 1200px The same with media queries /* Extra small devices (phones, 600px and down) */ @media only screen and (max-width: 600px) {...} /* Small devices (portrait tablets and large phones, 600px and up) */ @media only screen and (min-width: 600px) {...} /* Medium devices (landscape tablets, 768px and up) */ @media only screen and (min-width: 768px) {...} /* Large devices (laptops/desktops, 992px and up) */ @media only screen and (min-width: 992px) {...} /* Extra large devices (large laptops and desktops, 1200px and up) */ @media only screen and (min-width: 1200px) {...} These five Typical Device Breakpoints are represented by W3Schools as a well-accepted de facto standard.
