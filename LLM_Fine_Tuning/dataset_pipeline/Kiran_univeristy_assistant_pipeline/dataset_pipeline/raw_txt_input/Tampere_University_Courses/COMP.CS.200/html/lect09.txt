The problem: static web pages were not interactive, dynamic, or responsive. Partial fix: JavaScript that developers can use to add interactivity. The Problem: JavaScript cannot directly access or modify the content of an HTML document Solution: The DOM API What is the DOM? "The W3C Document Object Model (DOM) is a platform and language-neutral interface that allows programs and scripts to dynamically access and update the content, structure, and style of a document." - W3C W3C (World Wide Web Consortium) standard, first published in 1998. Core DOM - standard model for all document types - W3C DOM Specifications XML DOM - specializes in parsing, validating, and manipulating XML documents - XML DOM Level 3 Core Specification HTML DOM - what we use on our webpages - HTML Living Standard - DOM The HTML DOM is a model of a web page, structured as a tree, which the browser constructs upon loading the page. This is also known as the DOM tree. Click here to learn more What is the DOM tree? A hierarchical representation of the web page's structure element can have parent, children, and siblings in HTML document the root is always <html> element and it contains two mandatory children: head and body the nesting element is considered as a parent, inner elements are children rootward traversal enables the retrieval of ancestor nodes Elements can be accessed and manipulated using JavaScript Example of a DOM tree <html lang="en"> <head> <title>My Document</title> </head> <body> <h1>Header</h1> <p>Paragraph</p> </body> </html> Document represents the whole DOM tree The hierarchy as defined Grants access to global properties and information const title = document.title // returns the title of the document const url = document.URL // returns the URL of the document const contentType = document.contentType // e.g. 'text/html' manipulate the document's structure and content document.title = 'New Title' // sets the title of the document to 'New Title' // sets the background color of the body element to light blue document.body.style.backgroundColor = 'lightblue' //Access the first p element in the document const p = document.querySelector('p') Can be accessed using the document object Understanding the DOM Structure - Live DOM Viewer The DOM API How to use the DOM API The DOM API provides a set of interfaces and methods that allow programs and scripts to access and update the content, structure, and style of a document through the DOM tree, such as: interaction through event handling, like clicks and form submissions access to the document's structure and content dynamic manipulation of the document Example of DOM usage through the DOM API: const paragraphs = document.querySelectorAll("p"); // Selects the first element with class "demo" demoElement = document.querySelector("#demo"); // Selects the element with id "demo" demoElement = document.querySelector("div"); // Selects the first div element querySelectorAll : Selects all elements that match a CSS selector. const demoElements = document.querySelectorAll(".demo"); // Selects all elements with class "demo" demoElements = document.querySelectorAll("div"); // Selects all div elements Accessing Elements: Older vs. Newer Methods Specificity: older: More restricted—selects by ID, class, or tag name. newer: More flexible—supports full CSS selectors (similar to jQuery). Collection Type: older: Returns an HTMLCollection (live collection). newer: Returns a NodeList (static collection). Browser Support: older: Supported in all browsers. newer: Supported in modern browsers (IE9+). Event propagation Event Propagation: bubbling and capturing Events propagate through the DOM in three phases: Capturing phase: The event travels down from the root to the target element div1⬇️ div2⬇️ div3⬇️ div4⬇️ form⬇️ Target phase: the event reaches the target Bubbling phase: The event bubbles up from the target element to the root div1⬆️ div2⬆️ div3⬆️ div4⬆️ form⬆️ Note: Event listeners are usually set for either bubbling or capturing. If both are used, capturing occurs first. Stopping event propagation event.stopPropagation() stops an event from traveling further up or down the DOM, preventing parent/ancestor or child/descendant elements from receiving it. Its purpose is to control event flow and prevent unintended side effects, isolating event handling within specific elements. Use Cases preventing parent handlers (more usual use case) creating custom controls: building interactive components requiring precise control over event flow example: A custom dropdown in creating reusable UI components, stopPropagation can prevent the component's event listeners from interfering with the surrounding applications all major JavaScript frameworks (React, Angular, Vue.js) fundamentally rely on the DOM's event system and abstract away direct DOM manipulation but still work with the underlying event model. Event delegation for efficiency Instead of attaching event listeners to every individual element, event delegation attaches a single listener to a parent element. This listener then determines which child element triggered the event. Benefits: fewer event listeners mean less memory usage and faster processing handles events on elements added to the DOM after the listener is attached reduces the need for repetitive event listener setup Example: Handling "Customer" Actions Customer A Customer B Customer C Customer A... const customerList = document.getElementById('customerList'); customerList.addEventListener('click', function(event) { if (event.target.classList.contains('customer')) { const customerId = event.target.dataset.customerId; console.log('Customer clicked:', customerId); // Perform actions based on customerId alert(`Customer ${customerId} clicked!`); } }); Prevent default For example, a button's default type is submit triggered by click event To prevent this, use event.preventDefault() which keeps users on the same page: No unwanted refreshes. gives developers better control to decide when and how the action happens works with JavaScript-driven forms: needed for AJAX requests to prevents from full page reload essential for SPAs (Single Page Applications) done with React and Angular document.getElementById("myButton").addEventListener("click", function(event) { event.preventDefault(); // Prevents the default form submission }); To prevent event propagation (e.g., stopping an event from bubbling up the DOM tree), use event.stopPropagation(): element.addEventListener('click', function(event) { event.stopPropagation(); // Stops the event from propagating further }); Key Differences: event.preventDefault() → Prevents the default browser behavior (e.g., form submission, link navigation). event.stopPropagation() → Stops the event from traveling up or down the DOM tree.
