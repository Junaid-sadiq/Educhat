```plaintext
BinarySearch(array, target):
    left = 0
    right = length(array) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if array[mid] == target:
            return mid
        else if array[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1  // Target is not found in the array
```

2. **Loop Until Convergence**: Continue the loop as long as `left` is less than or equal to `right`.
3. **Calculate Midpoint**: Compute the midpoint `mid` to avoid potential overflow.
4. **Check Midpoint Value**:
   - If `array[mid]` is equal to the target, return `mid` as the index where the target is found.

   - If `array[mid]` is greater than the target, adjust the `right` pointer to `mid - 1` to search in the left half.
5. **Target Not Found**: If the loop exits without finding the target, return `-1` to indicate that the target is not present in the array.

The time complexity of binary search is \(O(\log n)\), where \(n\) is the number of elements in the array. This is because with each comparison, the algorithm effectively halves the search space, leading to a logarithmic number of steps.
