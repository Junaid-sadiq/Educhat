CSS-sääntösyntaksi

CSS-syntaksi selectorList { declaration }

Valitsin (selector), esim. elementin tyyppi, class tai id

selector[, selector]*
{ [property: value;]+ }

Sama sääntö pätee useisiin elementteihin 

h1, h2 { /* headers blue */ 
color: blue;
}

Useat samaan elementtiin kohdistetut säännöt 

body { /* page with black text */
color: black; /* on yellow background */
background-color: yellow;
}

Esimerkkisäännöt 

* { /* unifying margins and box sizing */
margin: 0;
box-sizing: border-box;
}
h1 { /* the first level header gets a black shadow */
text-shadow: 4px 4px 2px black;
}

p { /* text in paragraphs in red, and the width */
color: red; /* of the paragraph and the margin around it */
width: 240px; /* are defined */
margin: 3rem;
}
* on "universal selector" kaikille tyypeille

Menetelmä 1: Ulkoinen tyylitiedosto (linkitetty CSS-tiedosto)

Käyttää erillistä .css-tiedostoa (tai useampia tiedostoja), jotka liitetään <link>-elementillä <head>-osioon.

Tämä menetelmä mahdollistaa tyylien uudelleenkäytön useilla sivuilla, mikä parantaa ylläpidettävyyttä.

<head>
    <meta charset="UTF-8" />
    <title>Sivun otsikko</title>
    <link rel="stylesheet" type="text/css" href="polku/perustyyli.css" />
    <link rel="stylesheet" type="text/css" href="polku/navigaatio.css" />
    <link rel="stylesheet" type="text/css" href="polku/erityinen.css" />
</head>

Menetelmä 2: Sisäinen tyylitiedosto (<style>-lohko)

Määrittää CSS-säännöt suoraan <style>-elementissä <head>-osiossa.

Tyylit vaikuttavat vain tähän sivuun eikä niitä jaeta muiden sivujen kesken.

Hyödyllinen nopeisiin muokkauksiin tai yksittäisen sivun tyylien määrittelyyn, mutta vaikeammin ylläpidettävä suuremmissa projekteissa.

<html lang="fi">
<head>
    <meta charset="UTF-8" />
    <title>Sivun otsikko</title>
    <style>
    body {
        background-color: maroon;
        margin-left: 20px;
    }

    p {
        color: white;
    }
    </style>
</head>

Menetelmä 3: Sisäinen tyyli (inline-tyyli)

Suoraan elementtiin sivulla käyttämällä style-attribuuttia, eli niin kutsuttua sisäistä tyyliä (inline style).

Sääntöjen prioriteetit

Ristiriitaisten ja päällekkäisten sääntojen käsittely

Seuraavat kolme käsitettä vaikuttavat tyylien lopulliseen määräytymiseen.

Tarkkuus (Specificity)

  • Valitsimilla on tietty tarkkuusarvo.
  • Se sääntö, jolla on tarkin valitsin, "voittaa".

Periytyminen (Inheritance)

  • Jotkin ominaisuudet periytyvät vanhemmalta elementiltä (mutta eivät kaikki).

Kaskadoituminen (Cascading)

  • Jos useilla säännöillä on sama tarkkuusarvo, viimeisenä määritelty sääntö "voittaa".

Kaskadoituminen (Cascading)

  1. Selainkohtaiset oletustyylit (user-agent stylesheet).
  2. Käyttäjän tyylitiedosto, käyttäjän itse määrittelemät tyylit, esim. näkövammaisille käyttäjille (esim. Firefoxissa userContent.css-tiedoston kautta).
  3. Sivuston kehittäjän määrittelemät tyylit (author stylesheet), jotka voivat olla...
    • erillisenä CSS-tiedostona linkitettynä
    • HTML-tiedoston <head>-osiossa style-elementtinä
    • suoraan elementissä style-attribuuttina
    • kaskadointikerroksina 💥 uusi ominaisuus!

Lisätietoa monimutkaisemmista asioista (esim. siirtymät), katso MDN

Cascade layers (emerging)

  • Web Interop 2022 in action
    • cascade layers released at the same time by major browser vendors
  • more fine-grained author stylesheets
  • implemented with
    • @import
    • @layer
/*kerrokset alimmasta korkeimpaan prioriteettiin */
    @layer defaults, patterns, components, utilities, overrides;
    
    /* import stylesheets into a layer (dot syntax represents nesting) */
    @import url('webcais.css') layer(components.framework);
    
    /* lisää tyylit kerroksiin */
    @layer utilities {
        /* high layer priority, despite low specificity */
        [data-color='brand'] { 
        color: var(--brand, rebeccapurple);
        }
    }
    
    @layer defaults {
        /* higher specificity, but lower layer priority */
        a:any-link { color: maroon; }
    }
    
    /* kerroksettomilla tyyleillä (un-layered styles) on korkein prioriteetti */
    a {
        color: mediumvioletred;
    }

!important

  • ohittaa kaikki aiemmin elementille määritetyt säännöt
  • käytetään vain erityistilanteissa, esimerkiksi

CSS-yksiköt (pituusmitat)

                    
    
                        
  • Käytetään määrittämään pituuksia ja kokoja CSS-säännöissä.
                            Absoluuttiset yksiköt: in, cm, mm, pt, pc
                            
      
                                
    • Eivät yleensä sovellu näytölle, mutta voivat olla hyödyllisiä muissa
                                    medioissa.
      • 
                            
    
                        
  • Pikseli (px) on hyvin yleisesti käytetty yksikkö, esim.
                            
      
                                
    • min-width: 200px; font-size: 16px;
      • 
                            
    
                        
  • Absoluuttisten yksiköiden lisäksi monet yksiköt ovat suhteellisia
                            
      
                                
    • Suhteessa vanhemman elementin tai näkymäalueen kokoon.
      • 
                            
    
                        
  • Suhteellisia yksiköitä ovat: %, em, rem, ex, ch, vh, vw
                            
      
                                
    • Esimerkkejä: 16px, 0.75em, 1.25rem, 80%, 90vh, 85vw.
      • 
                            
    
                    

                

                

                    
Suhteelliset yksiköt

                    

                        %
                        Suhteessa vanhemman elementin mittoihin. Kätevä, jos vanhemman mitat on määritelty,
                        mutta voi olla hankala pystysuunnassa.
                        Jos vanhemmalla ei ole asetettua korkeutta, lapsen korkeusprosentti on aina 0.
                    

                    

                        em
                        Suhteessa vanhemman fonttikokoon (fontin korkeuteen). Useimmissa selaimissa
                        oletusfonttikoko (body-elementille) on 16px.
                    

                    

                        rem
                        Suhteessa juurielementin (html) fonttikokoon.
                    

                    

                        ex
                        Määrittää käytetyn fontin pienen "x"-kirjaimen korkeuden.
                    

                    

                        ch
                        Määrittää käytetyn fontin numeron "0" leveyden.

                                    se lasketaan näkymäalueesta (viewport).
                                    vh tarkoittaa prosenttia näkymän korkeudesta, vw leveyden prosenttia.
                                    100vh = 100% näkymän korkeudesta.
                            
                            1px = 1/96 tuumasta, ei suhteellinen. Vastaa yhtä laitteen pikseliä.
                                Korkean resoluution näytöillä (esim. Retina) 1px voi vastata useita laitteen
                                pikseleitä.
                            
                        

                        

                            vh ja vw eivät kärsi prosenttiyksiköiden rajoituksista.
                            Pikselin levyinen viiva pysyy aina terävänä.
                        

                    

                

                

                    
Esimerkkejä

                    

                        

                            
Useimmissa selaimissa oletusfonttikoko (body-elementille) on 16px.

                            
Fonttikoko on yksi periytyvistä ominaisuuksista:

                            
    
                                
  • Lapsielementit perivät vanhemman tekstikoon.
    • 
                                
  • Ei tarvitse erikseen määrittää, ellei haluta muuttaa kokoa.
    • 
                            

                            
Mitä yksiköitä kannattaa käyttää?

                            
    
                                
  • px kiinteille leveyksille (ei responsiivinen)
    • 
                                
  • %-yksiköt joustaville leveyksille (muuttuvat selainikkunan mukaan)
    • 
                                
  • em tai rem fonttikokoihin.
    • 
                            

                        


                        

                            

                                

                                        
body {
    font-size: 16px; /* Base font size */
}

article {
    font-size: 1.25em; 
    /* 25% larger than body (16px * 1.25 = 20px) */
}
