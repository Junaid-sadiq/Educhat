Johdanto DOM:iin

Miten päädyimme tähän?

  • Ongelma: staattiset verkkosivut eivät olleet interaktiivisia, dynaamisia tai responsiivisia.
  • Osittainen ratkaisu: JavaScript, jota kehittäjät voivat käyttää interaktiivisuuden lisäämiseen.
    • Ongelma: JavaScript ei voi suoraan käyttää tai muokata HTML-dokumentin sisältöä
    • Ratkaisu: DOM API

Mikä on DOM?

"W3C Document Object Model (DOM) on alusta- ja kieliriippumaton rajapinta, joka mahdollistaa ohjelmien ja skriptien dynaamisen pääsyn dokumentin sisältöön, rakenteeseen ja tyyliin sekä niiden päivittämisen." - W3C

  • W3C (World Wide Web Consortium) -standardi, julkaistu ensimmäisen kerran vuonna 1998.
    • Core DOM - standardimalli kaikille dokumenttityypeille - W3C DOM Specifications
    • XML DOM - erikoistunut XML-dokumenttien jäsentämiseen, validointiin ja muokkaamiseen - XML DOM Level 3 Core Specification
  • HTML DOM - mitä käytämme verkkosivuillamme - HTML Living Standard - DOM

HTML DOM on malli verkkosivusta, joka on rakennettu puuksi, jonka selain muodostaa sivun lataamisen yhteydessä. Tätä kutsutaan myös DOM-puuksi.

Mikä on DOM-puu?

  • Hierarkkinen esitys verkkosivun rakenteesta
    • elementillä voi olla vanhempi, lapsia ja sisaruksia
    • HTML-dokumentissa juuri on aina <html>-elementti, ja se sisältää kaksi pakollista lasta: head ja body
    • sisäkkäinen elementti katsotaan vanhemmaksi, sisäiset elementit ovat lapsia
    • juurisuuntainen kulku mahdollistaa esivanhempien solmujen hakemisen
  • Elementteihin pääsee käsiksi ja niitä voi muokata JavaScriptin avulla

Esimerkki DOM-puusta

<html lang="en">
                <head>
                    <title>My Document</title>
                </head>
                <body>
                    <h1>Header</h1>
                    <p>Paragraph</p>
                </body>
                </html>

Dokumentti edustaa koko DOM-puuta

  • Hierarkia määriteltynä
  • Pääsy globaaleihin ominaisuuksiin ja tietoihin 
    const title = document.title // palauttaa dokumentin otsikon
                const url = document.URL // palauttaa dokumentin URL-osoitteen
                const contentType = document.contentType // esim. 'text/html'
  • Dokumentin rakenteen ja sisällön muokkaaminen 
    document.title = 'Uusi Otsikko' // asettaa dokumentin otsikon 'Uusi Otsikko'
                // asettaa body-elementin taustavärin vaaleansiniseksi
                document.body.style.backgroundColor = 'lightblue' 
                // Pääsy ensimmäiseen p-elementtiin dokumentissa
                const p = document.querySelector('p')
  • Pääsy document-objektin avulla

DOM API

Kuinka käyttää DOM API:a

  • DOM API tarjoaa joukon rajapintoja ja menetelmiä, joiden avulla ohjelmat ja skriptit voivat käyttää ja päivittää dokumentin sisältöä, rakennetta ja tyyliä DOM-puun kautta, kuten:
    • vuorovaikutus tapahtumakäsittelyn kautta, kuten klikkaukset ja lomakkeiden lähetykset
    • pääsy dokumentin rakenteeseen ja sisältöön
    • dokumentin dynaaminen muokkaaminen
  • Esimerkki DOM:n käytöstä DOM API:n kautta: 
    const paragraphs = document.querySelectorAll("p");
                console.log(paragraphs[0].nodeName); // Tulostaa 'P'

Elementtien käsittely (Vanha tapa)

  • getElementById : Valitsee yksittäisen elementin sen ainutlaatuisen ID:n perusteella. 
    const demoElement = document.getElementById("demo"); 
                // Palauttaa yksittäisen elementin, jonka id="demo"
  • getElementsByClassName : Valitsee kaikki elementit, joilla on tietty luokan nimi. 
    const demoElements = document.getElementsByClassName("demo"); 
                // Palauttaa kokoelman elementtejä, joiden luokka on "demo"
  • getElementsByTagName : Valitsee kaikki elementit, joilla on tietty tagin nimi. 
    const demoElements = document.getElementsByTagName("div"); 
                // Palauttaa kokoelman kaikkia div-elementtejä

Elementtien käsittely (Uudempi tapa)

  • querySelector : Valitsee ensimmäisen elementin, joka vastaa CSS-valitsinta. 
    let demoElement = document.querySelector(".demo"); 
                // Valitsee ensimmäisen elementin, jonka luokka on "demo"
                
                demoElement = document.querySelector("#demo"); 
                // Valitsee elementin, jonka id on "demo"
                
                demoElement = document.querySelector("div"); 
                // Valitsee ensimmäisen div-elementin
  • querySelectorAll : Valitsee kaikki elementit, jotka vastaavat CSS-valitsinta. 
    const demoElements = document.querySelectorAll(".demo"); 
                // Valitsee kaikki elementit, joiden luokka on "demo"
                
                demoElements = document.querySelectorAll("div"); 
                // Valitsee kaikki div-elementit

Elementtien käsittely: Vanhemmat vs. Uudemmat menetelmät

  • Tarkkuus:
    1. vanhempi: Rajoitetumpi—valitsee ID:n, luokan tai tagin nimen perusteella.
    2. uudempi: Joustavampi—tukee täydellisiä CSS-valitsimia (samanlainen kuin jQuery).
  • Kokoelman tyyppi:
    1. vanhempi: Palauttaa HTMLCollection (dynaaminen kokoelma).
    2. uudempi: Palauttaa NodeList (staattinen kokoelma).
  • Selainyhteensopivuus:
    1. vanhempi: Tuettu kaikissa selaimissa.
    2. uudempi: Tuettu moderneissa selaimissa (IE9+).

Elementin sisällön käsittely

<div id="demo"><p>This is a <span style="display: none;">hidden</span> paragraph</p></div>
  • innerHTML : Hakee tai asettaa elementin HTML-sisällön (käytä varoen!) 
     element = document.getElementById("demo")
                    console.log(element.innerHTML) 
                    // Tulostaa: '<p>This is a <span style="display: none;">hidden</span> paragraph</p>'
  • innerText : Hakee tai asettaa elementin näkyvän tekstisisällön 
     element = document.getElementById("demo")
                    console.log(element.innerText)
                    // Tulostaa: 'This is a paragraph'
  • textContent : Hakee tai asettaa elementin tekstisisällön, mukaan lukien piilotettu teksti 
     element = document.getElementById("demo")
                    console.log(element.textContent)
                    // Tulostaa: 'This is a hidden paragraph'

Elementin attribuuttien käsittely

  • getAttribute : Hakee määritetyn attribuutin arvon 
     const src = document.getElementById("myImage").getAttribute("src");
  • setAttribute : Asettaa määritetyn attribuutin arvon 
     document.getElementById("myImage").setAttribute("src", "landscape.jpg");
  • removeAttribute : Poistaa määritetyn attribuutin 
     document.getElementById("myImage").removeAttribute("src");
  • hasAttribute : Tarkistaa, onko elementillä määritetty attribuutti 
     const hasSrc = document.getElementById("myImage").hasAttribute("src");

Elementin tyylien käsittely

  • style : Pääsee käsiksi elementin inline-tyyleihin ja muokkaa niitä 
     document.getElementById("demo").style.color = "red";
  • classList : Pääsee käsiksi elementin class-attribuuttiin ja muokkaa sitä 
     document.getElementById("demo").classList.add("red") // lisää luokan
                    document.getElementById("demo").classList.remove("red") // poistaa luokan
                    document.getElementById("demo").classList.toggle("red") // vaihtaa luokan
  • getComputedStyle : Hakee elementin kaikkien CSS-ominaisuuksien arvot 
     const styles = window.getComputedStyle(document.getElementById("demo")); // hakee lasketut tyylit
                    const color = styles.getPropertyValue("color"); // hakee tietyn tyylin arvon

Elementin mittojen käsittely

  • getBoundingClientRect : Hakee elementin koon ja sijainnin 
     const rect = document.getElementById("demo").getBoundingClientRect();
  • clientWidth ja clientHeight : Hakee elementin leveyden/korkeuden, mukaan lukien padding mutta ei border 
     const width = document.getElementById("demo").clientWidth;
  • offsetWidth ja offsetHeight : Hakee elementin leveyden/korkeuden, mukaan lukien padding ja border 
     const width = document.getElementById("demo").offsetWidth;
  • scrollWidth ja scrollHeight : Hakee elementin leveyden/korkeuden, mukaan lukien padding, border ja scrollbar 
     const width = document.getElementById("demo").scrollWidth;

Elementtien luominen ja lisääminen

  • createElement : Luo uuden elementin 
     const newElement = document.createElement("p");
  • append : Lisää uuden elementin vanhemman elementin viimeiseksi lapseksi 
     document.getElementById("demo").append(newElement);
  • prepend : Lisää uuden elementin vanhemman elementin ensimmäiseksi lapseksi 
     document.getElementById("demo").prepend(newElement);

Muita menetelmiä luomiseen ja lisäämiseen: appendChild, createTextNode , insertBefore , createDocumentFragment , cloneNode , insertAdjacentHTML ,

Elementtien poistaminen ja korvaaminen

  • remove : Poistaa elementin DOM:sta 
     document.getElementById("demo").remove();
  • removeChild : Poistaa määritetyn lapsielementin vanhemman elementistä 
     document.getElementById("demo").parentNode.removeChild(document.getElementById("demo"));
  • replaceChild : Korvaa määritetyn lapsielementin uudella elementillä 
     const newElement = document.createElement("p");
                    document.getElementById("demo").parentNode.replaceChild(newElement, document.getElementById("demo"));

Elementtien kloonaaminen

  • cloneNode : Luo kopion elementistä, mukaan lukien tai pois lukien lapsielementit 
     const clone = document.getElementById("demo").cloneNode(true); // true = syvä kopio, false = matala kopio
  • Syvä kopio: Sisältää kaikki lapsielementit ja niiden attribuutit
  • Matala kopio: Sisältää vain elementin itsensä ja sen attribuutit

Johdanto tapahtumiin

  • JavaScript on tapahtumapohjainen ohjelmointikieli, mikä tarkoittaa, että sen suoritusvirta määräytyy ensisijaisesti tapahtumien eikä tiukan lineaarisen järjestyksen mukaan.
  • Tapahtumat laukaistaan:
    • käyttäjän toiminnot: hoverit, vieritys, näppäinpainallukset, lomakkeiden lähetykset, ja paljon muuta...
    • ohjelmat: JavaScript voi luoda tapahtumia suorilla metodikutsuilla tai lähettämällä mukautettuja tapahtumia, mikä mahdollistaa dynaamisen käyttäytymisen. 
      // Klikkaustapahtuman laukaisu ohjelmallisesti
                    document.getElementById("myButton").click();
                    
                    // Muutostapahtuman laukaisu
                    document.getElementById("myInput").dispatchEvent(new Event("change"));
    • aikataulutetut toiminnot: ajastimet kuten `setTimeout` ja `setInterval` aikatauluttavat tapahtumia lisättäväksi JavaScriptin tapahtumajonoon
      • setTimeout(callback, delay) käskee ajonaikaa odottamaan vähintään delay millisekuntia ja sitten jonottamaan tapahtuman
      • callback on funktio, jonka annat setTimeout tai setInterval -kutsulle
      • Huom: setTimeout(callback, 0) ei suorita callbackia välittömästi, vaan jonottaa tapahtuman, joka laukaisee `callback`-funktion, kun synkroninen kutsupino on tyhjä
  • Tapahtumakäsittelijät: funktiot, jotka kutsutaan, kun tapahtuma tapahtuu

Tapahtumaobjekti (Osa 1)

Kun tapahtuma laukaistaan, luodaan tapahtumaobjekti:

  • sisältää tietoa tapahtumasta
  • voidaan käyttää tapahtuman käyttäytymisen hallintaan
  • voidaan välittää tapahtumakäsittelijöille
function logEvent(event) {
                        console.log(event); // Tulostaa tapahtuman 
                    }
                    
                    element.addEventListener("click", logEvent);

Tapahtumakäsittelijät: onevent

  • HTML-attribuuttina (ei suositella)
  • lisätty elementin ominaisuutena skriptissä: 
    1. function reportClick() {
                        console.log("Klikkaus tapahtui");
                    }
                    element.onclick = reportClick; // Määrittää funktion onclick-ominaisuudelle
    2. onchange: Kutsuu funktiota, kun elementin arvo muuttuu

Tapahtumakäsittelijät: tapahtumankuuntelijat

element.addEventListener(event, callback[, Boolean])
  • tapahtuma kuten 'click', 'mouseover', 'blur'
  • callback funktioidentifikaattorina, ei sulkeita
  • bubbling/capturing, oletusarvo false, mikä tarkoittaa bubbling
  • kuuntelijat lisätään/poistetaan skriptillä
  • addEventListener : Liittää tapahtumankuuntelijan elementtiin 
    function doSomething() {
                        console.log("Jotain tapahtui");
                    }
                    element.addEventListener("click", doSomething, false); // false(oletus) = bubbling, true = capturing, optional
  • removeEventListener: Poistaa tapahtumankuuntelijan elementistä. Vaatii viittauksen samaan funktioon 
    element.removeEventListener("click", doSomething, false); // false = bubbling, true = capturing
  • kohde-elementti toteuttaa EventTarget-rajapinnan tätä tapahtumankäsittelytukea varten

Tapahtumankuuntelijoiden esimerkki: Muistivuoto

function handleClick() {
                        console.log('Nappia klikattiin');
                    }
                    
                    const button = document.getElementById('myButton');
                    button.addEventListener('click', handleClick);
                    
                    // Myöhemmin koodissa...
                    button.parentNode.removeChild(button); // Poistaa napin DOM:sta

Lähempi tarkastelu kääreen sulkemiseen

function createHandler(num, text) {
                        return function (event) {  //closure!!!
                            console.log("Numero:", num, "Teksti:", text);
                            console.log("Tapahtumaobjekti:", event);
                        };
                    }
                    
                    document.getElementById("myButton")
                        .addEventListener("click", createHandler(42, "Hello!"));

    Sulku on funktio, joka "muistaa" ulomman laajuutensa muuttujat, vaikka kyseinen laajuus olisi jo suoritettu.

  • Sisäinen funktio on sulku, joka muistaa ulomman funktion num ja text
  • Sulut säilyttävät pääsyn ulomman funktion muuttujille
  • Kun createHandler(42, "Hello!") suoritetaan, se palauttaa funktion, joka tallentaa nämä arvot.

Mistä wrapperin event tulee?

  • Palautettu anonyymi funktio määritetään addEventListener-kutsuun, mutta se ei vielä suoritu
  • event-objekti välitetään automaattisesti ensimmäisenä parametrina tapahtumankuuntelijoille.
  • Kun tapahtuma tapahtuu, tapahtumankuuntelija antaa event-objektin callback-funktiolle.
  • Tämä mahdollistaa pääsyn sekä säilytettyihin muuttujiin (num, text) että tapahtumatietoihin.

Tapahtumien kulkeutuminen

Tapahtumien kulkeutuminen: bubbling ja capturing

Tapahtumat kulkeutuvat DOM:ssa kolmessa vaiheessa:

  1. Capturing-vaihe: Tapahtuma kulkee alas juuresta kohde-elementtiin

  2. Tavoitteessa: tapahtuma saavuttaa kohteen

  3. Bubbling-vaihe: tapahtuma lähtee etenemään takaisin juurta kohti

Huom: Tapahtumankuuntelijat asetetaan yleensä joko bubbling- tai capturing-vaiheeseen. Jos molempia käytetään, capturing tapahtuu ensin.

Tapahtumien leviämisen pysäyttäminen

event.stopPropagation() pysäyttää tapahtuman leviämisen ylös- tai alaspäin DOM:ssa, estäen vanhempia/esivanhempia tai lapsia/jälkeläisiä elementtejä vastaanottamasta sitä.

Sen tarkoitus on hallita tapahtumavirtaa ja estää ei-toivotut sivuvaikutukset, eristäen tapahtumankäsittelyn tiettyihin elementteihin.

Käyttötapaukset

  • vanhempien käsittelijöiden estäminen (yleisempi käyttötapaus)
  • mukautettujen ohjainten luominen:
    • interaktiivisten komponenttien rakentaminen, jotka vaativat tarkkaa hallintaa tapahtumavirran suhteen
    • esimerkki: Mukautettu pudotusvalikko
  • uudelleenkäytettävien käyttöliittymäkomponenttien luomisessa, stopPropagation voi estää komponentin tapahtumankuuntelijoita häiritsemästä ympäröiviä sovelluksia
    • kaikki suuret JavaScript-kehykset (React, Angular, Vue.js) perustuvat pohjimmiltaan DOM:n tapahtumajärjestelmään ja abstrahoivat suoran DOM-manipuloinnin, mutta toimivat silti taustalla olevan tapahtumamallin kanssa.

Tapahtumien delegointi tehokkuuden vuoksi

Sen sijaan, että liittäisit tapahtumankuuntelijoita jokaiseen yksittäiseen elementtiin, tapahtumien delegointi liittää yhden kuuntelijan vanhempaan elementtiin. Tämä kuuntelija määrittää sitten, mikä lapsielementti laukaisi tapahtuman.

Edut:

  • vähemmän tapahtumankuuntelijoita tarkoittaa vähemmän muistin käyttöä ja nopeampaa käsittelyä
  • käsittelee tapahtumia elementeissä, jotka lisätään DOM:iin kuuntelijan liittämisen jälkeen
  • vähentää tarvetta toistuvaan tapahtumankuuntelijoiden asettamiseen

Esimerkki: "Asiakas"-toimintojen käsittely

const customerList = document.getElementById('customerList');

                            if (event.target.classList.contains('customer')) {
                            const customerId = event.target.dataset.customerId;
                            console.log('Asiakas klikattu:', customerId);
                            // Suorita toimenpiteitä customerId:n perusteella

Oletustoiminnon estäminen

  • Esimerkiksi button-elementin oletustyyppi on submit, joka laukaistaan klikkaustapahtumalla
  • Estääksesi tämän, käytä event.preventDefault(), joka pitää käyttäjät samalla sivulla: Ei ei-toivottuja päivityksiä.
  • antaa kehittäjille paremman hallinnan päättää, milloin ja miten toiminto tapahtuu
  • toimii JavaScript-ohjatuissa lomakkeissa: tarvitaan AJAX-pyyntöihin estämään koko sivun uudelleenlataus
  • olennaista yksisivuisissa sovelluksissa (SPA), jotka on tehty Reactilla ja Angularilla
document.getElementById("myButton").addEventListener("click", function(event) {
                            event.preventDefault(); // Estää oletuslomakkeen lähetyksen
                        });

Estääksesi tapahtumien leviämisen (esim. estääksesi tapahtuman kuplimisen ylös DOM-puussa), käytä event.stopPropagation(): 

element.addEventListener('click', function(event) {
                            event.stopPropagation(); // Estää tapahtuman leviämisen edelleen
                        });

Keskeiset erot:

  • event.preventDefault() → Estää oletusselaimen toiminnan (esim. lomakkeen lähetys, linkin navigointi).
  • event.stopPropagation() → Estää tapahtuman leviämisen ylös tai alas DOM-puussa.
