How web works

Web page as a playload

General (HTTP/web)

familiarize with the basics of web development, tools and envs,
security concerns (e.g., CORS)

HTML
  • character encoding
  • promoted HTML5 conventions
    • e.g., semantic markup
    • media: audio, video
  • content model
  • tables, forms
  • validation
CSS
  • selectors and combinators
  • box model
  • display property, positioning, floating
  • flex, grid
  • media queries, Bootstrap
JavaScript
  • interaction and manipulation of DOM
  • variables and arrays, functions
  • form interactions
  • classes and objects
    • get/set, hide data
  • fetch data (AJAX)

Web page fetched as a GET request

Client (browser)

requests

  • by making GET with URL
  • request contains also other info, such as supported HTTP version, user agent (i.e., type of a browser,...)

HTTP transaction

Server (Apache, Nginx)

responses

  • status code the most important info,
    • 2XX signals success
    • 4XX user error, e.g.,
      404 not found (wrong URL)
  • response body
    • when Content-type is: application/html, the body is HTML
  • A user must know the URL of a service. URL is a human-readable name, not a numeric IP address.
  • The Domain Name System (DNS) solves the domain name (e.g. m.yle.fi) to a correct IP address.
  • The IP address is used in routing (network layer)
    • In the IPv4, addresses range from 0.0.0.0 to 255.255.255.255
  • On top of IP layer, TCP/UDP is used as a transport layer, more info

OSI vs TCP/IP model

OSI Layer TCP/IP layer Description Examples
Application Application enables apps communicate with each other, e.g., over HTTP HTTP, FTP, SMTP, DNS
Presentation en/de/crypts the content, compresses and formats data (e.g. char sets) -
Session establishes connections, manages sessions between applications RPC, SSH
Transport Transport controls network traffic, segments data, adds source and destination ports TCP/UDP
Network Network routes packets via best path between networks IP, ICMP (ping), routers
Data Link Data Link transfers data frames within a network MAC addresses, Ethernet, switches
Physical Physical transmits raw bit stream cables, hubs
Mnemonic: All People Seem To Need Data Protocols

W3 Consortium

A community for free and open Web standards

  • Member-driven organization, non-profit organization
  • W3C's vision for "One Web"
  • brings together thousands of dedicated technologists representing more than 400 member organizations and dozens of industry sectors.
  • W3C standards define an Open Web Platform for application development, such as
    • HTML
    • CSS
    • Scalable vector graphics (SVG)
    • Web open font format (WOFF)
    • the Semantic Web stack
    • XML
    • and a variety of other APIs
  • developers, designers, and anyone passionate about the Web have a place to hold discussions and publish ideas
For more information see https://www.w3.org/.

WHATWG: Driving Web Standards Evolution

WHATWG, a collaborative initiative, drives the evolution of web standards.

  • Founded in response to disagreements over the direction of web standards by industry leaders.
  • WHATWG champions innovation and progress in web technologies, including:
    • HTML, CSS, JavaScript APIs
    • Web APIs for multimedia, storage, and communication
    • Web Interface Definition Language (WebIDL)
    • and other emerging web technologies
  • Active participation from developers, designers, and enthusiasts fuels the continuous evolution of web standards within WHATWG's collaborative framework.

For more information, visit WHATWG's official website.

W3C validation

  • reveals mistakes that would otherwise go unnoticed
  • browsers render pages regardless of the mistakes in them
  • interpretation of erroneous code varies between browsers

HTML validation:
validator.w3.org

  • copy the HTML code into the validator direct input field, or
  • upload the code from your computer (Browse…), or
  • if published, just pass the address for the validator

CSS validation:
jigsaw.w3.org/css-validator/validator.html

  • as with HTML-code, either copy, upload or
  • pass the address of the whole file (which is attached with CSS code)
